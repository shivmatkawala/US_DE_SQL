2) How SQL Server Works in computer/server/machine

	1) what is SQL
		def of sql by ANSI:
			SQL is a standardized language used to communicate with and manage relational database management systems (RDBMS). It is designed to 			perform various operations like querying, updating, inserting, deleting data, and defining data structures and permissions.


	3) what is sql engine:
		An SQL engine is the part of a database management system (DBMS) that processes SQL queries. It interprets, executes, and optimizes your SQL 		commands to interact with the database, such as retrieving, updating, or managing data.

		Think of it as the "brain" of the DBMS that translates your SQL commands into actions on the database.



	4) what is ssms:
		SSMS (SQL Server Management Studio) is a tool developed by Microsoft that provides a graphical interface to manage, configure, and interact 		with SQL Server databases.


	5) what is database:
		A database is an organized collection of data stored electronically, making it easy to access, manage, and update.

		It allows you to store information (like records, files, or tables) and retrieve it efficiently whenever needed. Think of it as a digital 		filing cabinet for structured data.

	6) what is schema
		A schema is the blueprint or structure of a database. It defines how data is organized, including:
			1)Tables
			2Columns and their data types
			3)Relationships between tables
			4)Constraints (like primary keys, foreign keys)

		In simple terms, it's the layout or framework that describes how the database is set up.

	7) what is table:
		A table in a database is a structure used to store data in rows and columns, similar to a spreadsheet.
			Rows represent individual records.
			Columns represent the fields or attributes of the data.

		For example, a table for employees might have columns like Name, Age, and Salary, with each row containing data for one employee.


	8) what is column, row and record:
		Column: A vertical field in a table, representing a specific attribute (e.g., Name, Age).

		Row: A horizontal line in a table, representing a single entry of data.

		Record: A single, complete set of data (same as a row) for one entity (e.g., one employee's details).

	10) data types:
		INT: Stores whole numbers (e.g., 1, 100, -50).

		FLOAT: Stores approximate numeric values with floating-point precision (e.g., 3.14, 2.5).  

		DECIMAL (or NUMERIC): Stores fixed-point numbers with defined precision and scale (e.g., 123.45).

		CHAR: Stores fixed-length character strings (e.g., 'ABC'). Typically used for short text of fixed length.
		
		NVARCHAR: Stores variable-length character strings, Non-Unicode (UTF-8) (e.g., '')

		VARCHAR: Stores variable-length character strings, Non-Unicode (ASCII) (e.g., 'Hello World').

		TEXT: Stores large variable-length text data (up to 2GB).    # Being Scraped

		DATE: Stores date values (e.g., '2025-01-21').

		TIME: Stores time values (e.g., '14:30:00').

		DATETIME: Stores both date and time values (e.g., '2025-01-21 14:30:00').

		BIT: Stores binary values (0 or 1) to represent Boolean (True/False).

		BINARY: Stores fixed-length binary data (e.g., for images or files).

		MONEY: Stores monetary values with four decimal places.

		UNIQUEIDENTIFIER: Stores globally unique identifiers (GUIDs).

		XML: Stores XML formatted data.   # Being Scraped

23) wildcards to search for specified pattern in column
	SQL Wildcard Characters
		A wildcard character is used to substitute one or more characters in a string.

		Wildcard characters are used with the LIKE operator. The LIKE operator is used in a WHERE clause to search 
		for a specified pattern in a column.

		%	Represents zero or more characters

		_	Represents a single character

		[]	Represents any single character within the brackets *

		^	Represents any character not in the brackets *

		-	Represents any single character within the specified range *

		{}	Represents any escaped character **


	1) Searching for names that start with a specific letter
			SELECT * FROM Employees WHERE FirstName LIKE 'A%';


	2) Searching for names that end with a specific letter
			SELECT * FROM Employees WHERE FirstName LIKE '%n';


	3) Searching for names that contain a specific pattern
			SELECT * FROM Employees WHERE FirstName LIKE '%ar%';


	4) Searching for names that have a specific letter at a specific position
			SELECT * FROM Employees WHERE FirstName LIKE '_a%';

	5) Searching for names with a specific set of starting letters
			SELECT * FROM Employees WHERE FirstName LIKE '[AB]%';

	6) Searching for names that do NOT start with specific letters
			SELECT * FROM Employees WHERE FirstName LIKE '[^AB]%';

	
	7) Searching for names with specific characters in a specific position
			SELECT * FROM Employees WHERE FirstName LIKE 'J[ao]n';

	
	8) Searching for names in a specific alphabetical range
			SELECT * FROM Employees WHERE FirstName LIKE '[C-F]%';

	
	9) Searching for phone numbers with a specific format
			SELECT * FROM Customers WHERE Phone LIKE '555-____';


	10) Searching for email addresses in a specific domain
			SELECT * FROM Customers WHERE Email LIKE '%@gmail.com';


	11) Using Wildcards with NOT LIKE
			SELECT * FROM Employees WHERE FirstName NOT LIKE 'A%';
